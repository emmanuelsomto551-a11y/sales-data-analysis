# Sales Data Analysis & Business Insights System

## Project Overview

This project analyzes a sales dataset using Python and Pandas to identify sales patterns, clean data, create visualizations, and generate business insights.

## Objectives

- Inspect and understand the sales dataset.
- Clean and prepare the data for analysis.
- Perform exploratory data analysis.
- Create meaningful visualizations.
- Identify business insights.
- Build a reusable sales analysis pipeline.

## Dataset

The dataset contains 5,200 sales records and 9 original columns:

- order_id
- order_date
- product
- qty
- price
- region
- customer_id
- payment_method
- status
